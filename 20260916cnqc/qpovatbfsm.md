# 【今日关注】富奇志：ICU战场永不停息的女将

> 更新时间：2026-09-16 (UTC+8)

在ICU病房，

监测仪滴答作响，

闪烁着红红绿绿的生命体征。

一身青绿的医护人员

在这些危重症患者之间

走走停停，

不时查看，

一分钟都不敢松懈。

ICU，即重症医学科的简称，这个我们似乎多有耳闻的科室，集结着河南科技大学第一附属医院新区医院的精锐，如果说医院是一个生死较量的战场，那么这里的ICU团队便是先锋部队，他们技术精湛、作风优良，处理着各种棘手病例和突发情况。无将不得行，这样的“部队”必然有一位优秀的大将指挥，她便是富奇志，一位在医疗战场上的巾帼英雄。

**重症医学内科**

**河科大一附院·新区医院**

****
**富奇志，河南科技大学第一附属医院新区医院重症医学内科副主任（主持工作）兼神经内科副主任，医学博士，副主任医师，副教授，硕士生导师。曾赴美国梅奥医学中心（世界排名第一医院）进修1年。担任河南卒中重症学会副主委，洛阳市重症医学会常委等。擅长各种危重症的救治，如休克、呼衰、MODS、重症感染等，对急性脑血管病溶栓及个体化治疗、重症脑炎、神经系统疾病并发症等更有其独特的经验。已发表论著30余篇，曾多次参与或主持国家级、省市级科研项目，获洛阳市科技进步一等奖、河南省三八红旗手、河南科技大学第一附属医院优秀专家等荣誉。****面对科室，选择精心**

初见富主任时便发现她的脸色泛黄，嘴唇发白，不难想到进入ICU工作的6年时间中，富奇志经历着怎样频繁、高强度的工作。一个小时不到的采访，至少被打来的电话打断了三四次。听富主任讲，电话多早已是常态。“最开始进入ICU时，晚上每15分钟接一个电话，有时正洗着澡，电话就打过来了。”除了ICU科室的病人，向富主任征求治疗意见的还有全院各个科室的重症患者。

富主任说“ICU”就是“I see you（我看着你）”，是24小时连续不断的监护，并且要求多一分的精准和精细。有生命在这里匆匆离去，也有很多人从这里健康的走出。在河科大一附院新区医院ICU重症监护室，有高达98%治疗成功率。

精准、有效的治疗背后则是富奇志副主任带领的一个优秀团队。河科大一附院新区医院ICU重症监护室集结了可以说是全院诊疗、监护技术水平均在前列的团队。除了医术处在金字塔尖，这个团队气氛也格外“有爱”。“今年是新区ICU搬入新家的头一年，科室召开了生日庆典。每个人都给科室写了一句寄语。”富主任指着科室走廊里悬挂的照片墙上的一幅说道。

**面对信任，选择坚持**
富奇志副主任印象深刻的是曾经收治的一位15岁的高二男孩儿——他在郑州某医院被诊断为隐球菌性脑膜炎，在就诊的20多天时间中，高颅压等症状一直没有得到很好的控制，病情不断加重，孩子危在旦夕。同时，家人也在和死神赛跑，四处求医问诊，想为孩子再争取到一丝希望。但面对这样危重的病例，各大医院连连摇头。

孩子所感染的隐球菌性脑膜炎属真菌性脑膜炎的一种，作为一种深部真菌病，其病情发展迅速且程度严重，如不及时诊治死亡率极高。在河南省，患有这种疾病的病人并不罕见，病人的哥哥通过一个患者微信群听说了富奇志副主任所在的河科大一附院新区医院，在治疗真菌性脑膜炎上具有独到的经验。似是漫长的黑夜终于等到破晓，孩子一家旋即转到河科大一附院新区医院问诊就医。

这是一个各大医院无奈拒绝的危重病例，但更是一个尚在年少、仍存希望的年轻生命，看着病床上奄奄一息的孩子，富奇志带领的ICU病房怎么也没法拒绝，最后向孩子一家点了头，同意收治。后期检查发现，孩子同时还伴有脑部结核杆菌感染。面对这样的危重病情，富奇志副主任带领的整个ICU团队都不由得绷紧了神经。

持续癫痫、高颅压、呕吐、消化不良、脑积水、呼吸衰竭……无数的难题摆在了富奇志主任面前。但在ICU病房及时、精准的治疗控制下，加上全院多个科室的联合救治，孩子在死亡线上同医护人员“共同作战”了三个多月后，病情最终有了好转。直到真菌、结核杆菌最后“投降撤军”，这场生命的“持久战”足足打了一年有半。

在这段期间，富奇志副主任经历了孩子多方面并发症的起起伏伏，也听到了孩子家属“为什么这么久都治不好？这病就那么难治吗……”的不解和质问。但看着孩子爸爸妈妈的坚持和信任，她怎么也不能放弃，最终从死神手里把这个15岁的男孩拽了回来。这才有了后来孩子顺利考上大学，才有了这一大家子的其乐融融。
**面对工作，无奈家庭**

“我希望2017年在我洗澡的时候、和我的孩子共处的时候、睡觉的时候，不看微信、不接电话。”这是富志奇主任被问到“2017年最想实现的一件事情是什么”时给出的答案。

去年岁末的愿望转眼就被繁忙的工作掩盖。作为ICU的负责人，她24小时都要掌控病人的情况。“进入ICU的重症患者没有时间等待，一个大夫肯定是不够的，病情需要高年资医师来进行准确评估。”病人被送到病房时，即使她当时不在科室，之后也一定会迅速介入。有时深夜突然被叫回科室，富主任也只能开车返回。夜已深，宽阔的马路上，路灯明亮，一人疾驶回院，富主任笑笑说“我觉得挺酷的。”

每天几乎24小时“在线”，平均15分钟接听一个电话的生活已然成为她的主线。“我没有生活，只有工作。”面对工作和家庭，富主任多有无奈，家里的女儿即将面临高三，报辅导班、自主招生等事情，她一点都顾不上。“孩子曾经跟我说过‘妈妈，我恨不得把你的电话摔了。’”
**面对事业，选择传承**
富奇志一家是医学世家，丈夫是河科大一附院的乳腺外科副主任，女儿的爷爷奶奶也都是医院的老专家，但是富主任并不想让女儿做医生。但听着父母时常在家里谈论病人的故事，耳濡目染下，本来文笔很好准备学文科的女儿竟“弃文从医”，准备考取医学专业。而当问及女儿想要从事的科室时，她做出了和妈妈一样的选择——“我想当重症医生。”

富奇志副主任面对女儿的选择有作为母亲的无奈，但是更多的则是作为一名医生母亲的欣慰和自豪。鲜有时间陪伴孩子也使富主任的女儿十分独立、成熟。“妈妈，我想做一个对他人有用的人，这样价值才能体现。”富主任便是那个救助了无数“他人”生命的人，这个有价值的角色在不远的未来也会由她的女儿承担。

家庭之外，这种传承的精神也流传在科室。富奇志副主任常说“患者转危为安，就是对我们最大的回报。”ICU科室里的医生，正如孙思邈《大医精诚》所述“不得瞻前顾后，自虑吉凶，护惜身命。见彼苦恼，若己有之，深心凄怆。 ”富奇志除了临床、科研工作之外，十分注重青年医师护士的培养、科室文化的建设。“当我们这些专家老了退休了，我们要把专业的精神和操守传承下去，技术可以自己去学，精神是最为重要的。”这股精神是对专精医术的坚守、是治疗照顾每一位患者的缜密与精心、是面对突发和严峻问题时不顾一切的勇气、是不顾工作覆盖生活的付出与奉献……
